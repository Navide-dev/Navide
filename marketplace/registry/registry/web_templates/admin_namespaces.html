Frozen namespaces

A namespace is frozen when its owner's developer qualification is revoked or a grandfathered namespace's grace period ends without an approved application. A frozen name takes no slot and is never released. Unfreezing gives it back to the same account only, once that account is an approved developer again; it never goes to another account. The old publisher tokens and keys stay revoked: the owner issues a new token and registers a new key. Versions stay yanked and their digests blocked unless you tick "Restore versions", which undoes only what this freeze did: a block left from an earlier freeze (unfrozen without restoring) stays, and so does a digest that a namespace still frozen also uses. Remove those on the Blocklist page if needed.
