Before you publish: the checklist

Review looks at these five things.

  • navide-plugin scan shows an empty red list: no undeclared capability, no likely credential.
  • The package is signed with the key registered on your dashboard (otherwise 403 invalid package signature).
  • README, CHANGELOG and icon are included, and the name is not close to an existing extension's.
  • permissions declares only what you use; adding one later asks users again.
  • With a backend, one package per platform; a version number is never reused.
navide-plugin publish acme.hello-1.0.0-darwin-arm64.vsix
# human review, target: 3 business days
navide-plugin status acme.hello
